# Portfolio

My personal portfolio built with **React** and styled with **Tailwind CSS**.

[teodorlien.com](https://teodorlien.com)

## Getting Started

To run the project locally:

1. Clone the repository:

```
git clone https://github.com/Teodor29/portfolio
cd portfolio
```

2. Install dependencies:

```
npm install
```

3. Start the development server:

```
npm run dev
```
